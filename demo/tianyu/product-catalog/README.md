# 完整产品资料

12个产品主题覆盖定位、AI工作方式、工作资料沉淀、客户与权限、商机与渠道、审批、行动日程、交付收款、穿透分析、企业集成、本地部署与行业路径。另有10个产品问答及30分钟讲解路径。

打开 `产品资料导航.html` 选择专题。源码目录的场景链接指向相邻 `product-story`；运行 `build_product_catalog.py` 后交付目录的链接转换为同目录现有场景页，保留用户原文件。公开压缩包仅包含8份HTML和9张主图，不复制用户图片副本或任何内部PDF。

通用产品内容依据既有应用服务、操作说明及本轮验证；虚构天雨用于行业示例。持续采集和外部副作用按实际授权配置，不把营销场景写成后台已全量监听。真实企业案例PDF及其生成脚本只在本机私有目录保存。
