## 阶段和金额判断

PPT形成线索；有效报价形成商机；反复报价分别保留版本和内部工作过程；合同草稿表示方案进入确认，不表示已经签约。已有正式合同只引用，不重复建立已赢商机。金额未知或版本冲突保留空值和待核实，不以零代替。终端项目金额、渠道甲方付给我方的金额与软件返佣分别记录。

## 历史和未来分开

34条历史记录保留资料的原始日期、沟通/听记或报价修订依据；36项未来建议以`ai_recommend`来源保存，关联负责人、商机、知识证据及36个本地日程。不把排程变成客户已确认的承诺，不把计划变成实际回款。

## 数据边界

公开包仅包含虚构来源`demo://TIANYU/...`。运行生成器无需访问其他帐套或私人工作文档。实际AI使用需要用户授权资料访问；CRM提供业务接口，不自行读取所有聊天和录音。钉钉、飞书的真实连接另行配置，演示安装不调用外部服务。
