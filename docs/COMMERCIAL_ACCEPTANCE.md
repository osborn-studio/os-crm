# 商用验收清单与阻断项

2026-11-01。目标为企业自有环境安装的AI原生CRM。当前为多批候选，尚不满足最终商用验收。下表把工程自测、业务验收和外部联调分开；最终验收需要产品负责人在指定版本、环境和范围下确认，不能由提交数量或测试数量代替。

## 当前可复验的闭环

| 闭环 | 可执行证据 | 状态 |
| --- | --- | --- |
| 空企业安装、随机密钥、重启、加密备份和新库恢复 | production-smoke、Linux Docker工作流 | 工程候选通过，目标客户环境待验收 |
| 四角色账号、部门、调岗、停用、会话撤销、密码与刷新轮换 | identity-smoke | 工程候选通过，邀请/MFA待补 |
| 客户导入预检/去重、销售交接、报价版本、合同审批与未执行变更 | commercial-smoke | 工程候选通过，主体合并及执行后补偿待补 |
| 订单、项目、任务、工时累计、里程碑、独立验收和拒收整改 | smoke、交付及交接操作手册 | 工程候选通过，附件和售后待补 |
| 收款登记、独立复核、核销/撤销、同凭据更正、非空升级恢复 | finance-smoke、receipt-upgrade-smoke | 工程候选通过，非完整财务软件 |
| 顺序审批、版本快照、拒绝/撤回、转审、管理员恢复与离职交接 | approval-transfer-smoke | 工程候选通过，会签/加签待补 |
| 生产依赖已知漏洞检查 | pnpm audit --prod；CI阻断 | 当前锁文件清零，剩余构建链告警待治理 |

版本、库后缀、实际计数和云端链接以PROGRESS为准；不同批次同一检查不累计成独立覆盖量。

## 按优先级继续完成

| 优先级 | 阻断事项 | 关闭标准 |
| --- | --- | --- |
| P0 | AI仍是人类身份只读MCP，无独立委托执行 | 独立限时/限能力委托、预演、授权、同业务服务执行、幂等回执、撤销和提示注入回归；模型配置和上下文不得越权 |
| P0 | 交付证据目前仅文本，售后/服务工单缺少闭环 | 私有附件上传/下载权限、恢复覆盖附件；售后提交、指派、处理、复核关闭及历史 |
| P0 | 通用审批复杂路径和可靠外发未完成 | 会签/加签/转审组合、超时处理、不可变快照、事务outbox、重试与死信及补偿；不丢失或重复执行业务回调 |
| P0 | 发布/升级与运行保障不足 | 指定版本升级备份/迁移/回退演练；TLS/反代、健康/监控告警、数据导出与保留、容量指标和目标OS实测 |
| P0 | 实际企业钉钉/飞书联调未完成 | 获得测试企业凭证及范围后，各自验证身份映射、免登/回调验签防重放、租户隔离、撤销与失败对账 |
| P1 | 执行中合同/订单变更的补偿、取消与分批交付 | 用已有交付和收款样本验证允许/拒绝边界，不静默改写已执行数据 |
| P1 | 分期计划、完整分页/导出及账龄 | 真实金额/日期、权限过滤、余额勾稽、导出一致性与大数据量验证 |
| P1 | 构建链中低危依赖和镜像工具保留 | 升级修复或构建运行分离，并复查实际镜像；例外由负责人明确接受，不能默认豁免 |

银行转账、税控开票、会计记账和真实退款原先允许作为明确未开放的财务展示，不默认纳入本地CRM第一期上线验收。若实际客户要求这些能力，应单独确认范围、接口和业务验收，不能用本地台账模拟替代。

## 最终交付记录

每个发布候选需包含源码版本/校验值、安装与升级手册、角色及权限矩阵、功能手册、演示与合成样本、已知限制和逐项验收回执。当前PR保持可审核且未合并，不在公网或客户生产环境部署。满足工程门槛后再请负责人验收具体版本；不提前请求空泛批准。
