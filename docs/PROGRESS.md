## C2 人员与会话闭环候选

- 新增服务端持久会话与刷新哈希，访问令牌逐请求检查会话、用户和企业；主动退出撤销当前会话，退出全部设备及重置/修改密码撤销全部目标会话。

- 人员创建/角色赋予、调岗/停用、密码重置与部门保存均使用严格参数、当前认证身份、事务、幂等、版本与审计；禁止跨企业关联、自我停用/降权、关闭最后管理员及未交接的待审批人员变更。
- 四种预置角色每个账号四选一；角色定义写入口暂关闭。管理页增加查询/分页、部门维护、停用与密码重置；新增账号安全页面。人员迁出、停用或失去适用角色会清除旧负责人引用。共享写入事务会重新核对会话、角色、数据范围与权限，关闭认证与提交之间的撤销竞态。
- 新增可过滤的身份能力目录，包含版本、JSON输入/输出 schema、权限/效果/状态与证据；当前不开放身份管理 MCP 写入。
- 数据恢复会明确撤销备份中的旧会话并轮换签名；迁移不重置密码，旧无会话编号 JWT 要求重新登录。
