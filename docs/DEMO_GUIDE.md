# C11 演示指南

当前为演示与合成数据测试的工程候选，尚未生产验收。[完整演示手册](releases/C11/伴圆CRM_演示手册_C11.md)提供20分钟脚本、前置条件和现场问答；[逐项操作手册](releases/C11/伴圆CRM_逐项功能操作手册_C11.md)覆盖14类资源字段及新增闭环；[部署入口](DELIVERY.md)区分演示与空企业安装。

本机http://localhost:3000；admin、manager、sales、boss四个演示账号密码均为12345。正式企业使用独立强密码，不能把演示账号当成生产账号。

建议顺序：老板经营下钻 → 销售客户、线索、商机报价 → 合同审批及签约 → 订单/立项 → 任务、里程碑、独立验收与整改 → 会签与人员交接 → 本地收款复核/核销/更正 → 售后独立关闭及私有附件 → AI委托预演、原人批准、代理执行和回执。

标准种子包含40客户、60联系人、20线索、24商机、12合同及关联订单、项目、计划和合成财务。新增C7—C11状态不保证已预置，先按手册在独立演示副本建立合成记录和足够的独立复核人员。历史已完成项目不能自动当作新版验收通过项目。

`pnpm demo:reset`在有本机建库权限的原生环境创建新演示副本并切换.env，保留旧库；`pnpm demo:test`创建独立测试库；`pnpm check`执行类型、lint、自动化和构建。已有正式库不重跑演示种子。

AI摘要仍为规则生成；人工MCP只读与独立受控委托是两类入口。详见[AI接入说明](AGENT_DELEGATION_OPERATIONS.md)。台账不代表银行到账；撤销核销不代表退款。钉钉飞书仍待真实企业联调，免登和外部审批回调尚未开放。
