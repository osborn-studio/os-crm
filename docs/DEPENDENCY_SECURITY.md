## 进程存活与数据库就绪

`GET /api/v1/health`仅表示进程存活；新增`GET /api/v1/health/ready`实际执行固定`SELECT 1`。数据库失败或2秒超时返回503，响应不暴露数据库地址、凭证、业务记录或驱动错误。成功和明确失败短暂缓存1秒，因此状态变化可能延迟最多约1秒；并发请求共享一个查询，慢数据库不会因健康请求叠加查询队列。

正式/演示Compose健康检查、容器及本地演示启动、正式安装验证改用ready路径。该检查只证明数据库可达，不证明迁移版本、磁盘容量、备份时效、外部平台可用或业务已验收。测试包含固定查询、缓存、故障503、超时、并发合并和故障恢复；新增真实HTTP检查及安装/新库恢复检查覆盖实际就绪路径。
