# 公开资料与真实企业数据隔离

当前公开业务样本只使用虚构的天雨阀门。生成器只能读取确定性模板，不能读取另一个公司的数据库、工作文件、聊天、听记、报价或录音后换名导出。可以复用业务规则和链路设计，不能把真实记录当作“脱敏样本”直接公开。

## 可以发布

通用源码、数据库结构迁移、操作及开发说明、合成单元/集成测试、天雨生成器及数据包、确认属于天雨的过程截图、虚构资料和审批内容。旧兼容性测试的合成身份仅用于回归，不能当成真实企业数据。

## 不进入Git或Release

真实企业的客户/人员、合同、报价、发票、收款、日程、聊天、听记和跟进计划；`.local`、`.env`、导入导出目录、数据库转储、公司连接配置、令牌、私钥、备份及恢复密钥。正式公司保持独立数据库与连接账号，不能从演示脚本切换到正式公司。

## 发布检查

`pnpm public:audit`检查当前跟踪/新增文件的路径、公开数据归属、压缩数据与生成器一致性，以及可识别的凭证内容。压缩业务数据只允许`demo/tianyu/data.jsonl.gz`；SQL只允许结构迁移；旧升级测试归档以固定合成测试例外保留。打包器在干净提交中复制当前受检文件，不接收任意本地资料目录。

机器检查不能代替业务内容审核。发布前仍需核对新增文本、图片及办公文档的来源；私有扫描清单和真实数据核对回执留在本机，不进入公开报告。移除旧发布资产前保留本地副本和摘要，不通过清理操作修改真实公司数据。
