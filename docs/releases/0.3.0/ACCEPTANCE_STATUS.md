## 本批验证

- 最新工程：314项API、4项安装/加密、19项帐套/代理配置测试及类型、lint、构建；钉钉合成CLI协议真实MySQL65项、旧库智能体升级26项通过。
- 独立真实MySQL：报表55项、公司隔离与丰富链路47项、客户合同325项、收款326项；数据均为合成，未写入正式公司。
- 分期合同：合计不符及无条款拒绝、分期跨年、分到最小货币单位、并发同请求不重复生成。
- 公司隔离：数据库和连接用户独立，SQL跨库拒绝，令牌/密码跨公司拒绝。
- 正式帐套：16类业务表仍为空。原管理员及4种角色保留，真实组织新增15部门、30个停用人员，11位新人员待核定CRM部门；旧样例数据先加密备份校验后退出。
- 网页：正式登录、空业务报表、390像素导航、公司管理和外网配置自检；本机发起LAN HTTP可用，LAN访问管理控制面403。
- 备份：正式公司初始归档已做认证解密校验；新增本机整套新库/独立账号恢复，逐表/附件Hash与恢复后业务已在隔离环境验证；跨机器断电灾备和正式切换未验收。
- 发布依赖：发现新公告后修复Hono间接依赖；最新工程/容器/数据库云端状态以[PR #22](https://github.com/osborn-studio/os-crm/pull/22)当前检查为准。

本批未重做所有模块的完整人工验收；历史CI记录不能替代本次真实公司端到端试用。
