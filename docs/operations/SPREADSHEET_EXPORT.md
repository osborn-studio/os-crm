# Excel 与 CSV 导出

客户、商机、合同等业务列表及销售预测/回款统计，均提供“导出 Excel”和“导出 CSV”。只导出当前权限、当前筛选下的当前页，不在后台额外读取其他公司或不可见记录；文件名含“当前页”。导出不会修改业务数据。

## 操作

1. 进入业务列表或“销售预测与回款分析”，选择期间、负责人/部门、状态等需要的口径。
2. 核对页码和当前页记录，点击“导出 Excel”。需要更多记录时先翻页；本功能不是完整数据库备份。
3. Excel文件包含标题、冻结首行、列筛选和两位小数金额格式。客户/联系人、合同编号、带前导零的编码和日期作为文本保存，数值金额可以求和；统计状态使用中文，未知加权明确标注“不纳入加权”。
4. 合同年度矩阵导出包括每个月计划和已回金额。报表中的计划、实际到账、当前未收和当前逾期保持各自口径，不混为收入或利润。
5. 需要CSV时选择相应按钮。它面向电子表格查看：危险前缀的文本会加制表符和文本标记，字段内逗号、引号、换行仍在同一字段内。程序化无损交换请使用受权限控制的接口；完整备份使用[整套恢复工具](LOCAL_RECOVERY.md)。

## 数据与安全规则

XLSX中用户文本使用明确的字符串单元格，文件不生成公式、宏或外部链接。大于Excel15位有效数字能力的金额保留为文本，避免悄悄四舍五入；此类金额需要精确十进制工具计算。非法XML控制字符按OpenXML转义保留，不把原数据改写成公式。

CSV不能替代具有单元格类型的XLSX。公式前缀检测覆盖空白/控制/不可见字符及全角变体；引用字段和双写引号阻止分隔符逃逸。不同表格软件、保存和重开方式可能改变CSV解释，因此默认提供XLSX，不能承诺CSV在所有软件中具有相同语义。参考[OWASP CSV Injection](https://community.owasp.org/attacks/CSV_Injection)和[微软Escaped String规范](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-oi29500/d34ae755-c53f-4a44-a363-c6dd3ee018a4)。

## 实际验证

本机工程通过314项API、4项安装加密、19项帐套、6项恢复/服务及新增10项导出测试，类型、lint和构建通过。导出测试覆盖危险文本、空白/控制/全角前缀、引号分隔符、无公式/宏/外部链接、编码前导零、超精度金额、冻结筛选和无效输入。

浏览器实际下载客户XLSX、客户CSV与销售预测XLSX，独立使用Python csv解析、ZIP CRC/XML解析和openpyxl3.1.5读回28项检查通过；最终报表另6项检查通过，商机金额871500、加权284100与页面/业务核对值一致，金额为数字、状态中文、日期不带时分秒。名称为无害公式样文本的【测试】客户保持字符串，不产生公式。全部数据仅在隔离测试库。

本机未安装Microsoft Excel，未声称已完成Excel桌面保存/重开实测。当前提交云端结论以PR检查为准。
