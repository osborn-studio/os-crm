# 合同、回款与渠道业绩

经营工作台及销售统计首先展示七项可以回到合同和单据核对的金额。报表在公司独立数据库中运行；人员范围遵守当前账号的本人、部门及下属团队、全公司权限。日期可选2010—2060年，统一采用上海业务日。

## 七项主指标

| 指标 | 计算及口径 |
|---|---|
| 合同总金额 | 所选签约日期和人员范围内，人民币、已签约/执行中/已完成的我方业务合同金额。软件返佣单列，草稿与取消不纳入。 |
| 合同已收款 | 同一批业务合同已核对到合同上的累计收款，使用 `totalReceived`；未复核及未归属合同的款另查收款台账。 |
| 合同待收款 | 同一批业务合同当前 `totalOutstanding` 的合计。与收款计划及核销数据核对，不把未收算成实收。 |
| 已开票金额 | 同一批合同截至当前有效销项发票累计；待开、作废、红冲及进项不纳入。 |
| 已开票已收款 | 有效发票已关联并核对收到的金额；无法完整匹配时不推定为零，显示待核实。 |
| 已开票待收款 | 每张有效发票金额减去其关联分期的已核销金额，下限为零。分期链接须完整覆盖发票；存在无法归属的发票时显示待核实，同时单列已确认部分。 |
| 在建项目金额 | 同一批合同中，可见的在建/暂停项目所关联的合同金额；每份合同只计一次。已完成、运维、关闭项目不纳入。无项目模块权限时不以零冒充公司数据。 |

“待收款”就是还没有收到的钱；已开票待收款属于合同待收款的一部分，不能再相加。

这七项采用**签约合同批次**，不是各类单据各自日期的混合总额。开票与余额为该批合同当前累计值，不是所选结束日的历史快照。需要按到账日或计划预计收款日核对时，进入原有回款台账分析。点击指标查看相同口径的合同明细；合同链接可以打开业务单据。

## 渠道身份与来源分别维护

“销售渠道客户”表示交易对方身份，可标记用友、钉钉、阿里或其他。渠道作为甲方支付给我们的实施、开发和外包等费用，计入我方业务业绩。软件返佣作为独立性质，展示返佣合同、已收和未收，不并入业务业绩。

一个终端客户的项目来自渠道，仍保留终端客户身份。资料导入将渠道来源保存在销售事项/来源元数据，不再据此把终端客户改为渠道甲方。往来表按照合同实际客户归集，不能把所有使用某厂商产品的单子计到该厂商名下。

管理员在合同或商机详情的“交易性质与业绩口径”中确认分类，填写依据。商机可拆分我方业务金额和厂商产品报价，已知两项之和必须等于原报价。原报价和报价版本不被改写。报价变化后，旧拆分失效并等待重新核实，不能自动拿整包价格替代我方金额。月费期限不明、单价及未知金额继续排除金额预测。

未分类合同暂按业务统计，界面展示待核标识和数量。不能用合同类型或客户名称猜测所有交易性质，例如厂商甲方的服务合同不等于软件返佣。

## 回款安排的初始规则

这是帮助跟催的规则估计，尚未用历史样本校准为成交概率。

| 条件 | 权重调整与时间安排 |
|---|---|
| 起点 | 50 |
| 同合同有已收款 | +10 |
| 分期关联有效销项发票 | +15 |
| 可见项目已通过验收或完成 | +10 |
| 分期已填预计收款日期 | +5 |
| 逾期31—90天 / 超过90天 | -15 / -25；暂排今天后30 / 60天 |
| 预计收款日未填或合同分期余额不一致 | -15；暂排今天后60天，显示具体待核原因 |
| 预计收款日未来 / 已到期但不超过30天 | 未来按预计收款日且至少保留7天；已到期暂留14天跟催窗口 |
| 可见项目计划完工晚于上述安排 | 推至计划完工后14天，标明计划日期须核实 |

权重限制20—90；逐笔金额乘权重按分四舍五入。原待回金额与加权参考分别显示，按未来30天、31—60天、61—90天及以后分组。日期是推进安排，不是客户承诺。只分配合同未回余额，**不再叠加开票未回余额**；分期与合同余额不一致时只用一笔合同余额，不重复计数。

历史在建登记是管理员受控资料操作：沿用已签合同、当前版本和有效负责人，复用已有项目，记录来源与估算计划日期。它不创建真实签署、开工、验收、收款或新审批事实，不发送历史群通知。普通新项目仍走立项审批。

## 网页与智能体

- `report.business.cash@1.0`：`GET /analytics/business`，必须同时具备财务与合同读取权限，项目数据另受项目权限约束。网页、人工MCP和明确勾选该项的智能体委托调用同一服务。
- `sales.trade.classify@1.0`：`POST /trade/classify`，管理员确认交易性质/金额拆分。事务、幂等、当前版本和审计，保留历次分类。不开放智能体直接写入。
- `project.history.register@1.0`：`POST /trade/project-register`，管理员历史在建登记，同样保留版本和审计。不开放智能体直接写入。
- 统计明细使用服务端排序再分页，正反序按钮与权限过滤一致。各报表拒绝超过10000条的查询，不返回截断总数。

当前经营统计使用人民币合同，其他币种不能直接相加。银行、税务验证及会计收入确认不是这套经营指标的含义。
