# 业务与统计排序

每个表格提供“排序依据”和独立的“正序 ↑ / 倒序 ↓”按钮。日期正序为早到晚，倒序为晚到早；金额正序为小到大，名称按中文与数字顺序比较。可以点击支持排序的表头切换方向。

- 行动计划默认到期日期正序；客户、商机、合同、订单、项目、任务、跟进、产品、回款计划、开票和收款等业务列表可按页面提供的日期、名称、金额或状态排序。
- 商机看板按照相同排序查询，再将当前页卡片分入阶段；看板仍明确显示本页阶段汇总，完整汇总见统计。
- 销售预测和回款分析的钻取明细先排序全部匹配结果，再分页。切换按钮回到第一页；导出沿用当前页排序。
- 客户分配、人员账号和历史资料原表也在服务端排序后分页。资料排序只改变显示，原文件、行号和来源证据不变。
- 月度统计、人员分布、账龄、漏斗及已加载的关联记录使用同一组按钮。对完整加载的表格，排序覆盖全部加载结果后再做前端分页；“最近50条”等限量记录只在明确显示的范围内排序。

空日期和未知金额排在末尾。相同值用编号稳定排序；金额比较保留精度。按月统计跨年时同时比较年份和月份，不将不同年份的同月混排。

所有排序在现有公司、模块、人员和记录权限过滤后生效，不扩大数据权限。排序字段使用服务端白名单，不能借排序读取隐藏字段。AI/HTTP报表可使用 `sortBy` 与 `sortOrder=asc|desc`；各资源允许的字段由能力契约返回。

验证包括类型、静态检查、单元测试、构建，以及独立 MySQL 数据库上的跨页日期/金额排序、空值末尾、无效字段与越权拒绝。具体运行证据见 `docs/PROGRESS.md`。
