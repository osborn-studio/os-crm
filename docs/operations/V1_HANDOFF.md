# V1本地使用交付说明

本次确立第一版界面及经营口径。程序包仍沿用仓库0.3.0版本号；V1表示此次交付节点。生产环境的最终验收由安装环境、真实业务及外部接口共同完成。

## 已落实的操作

- 合同总金额、合同已收款、合同待收款、已开票金额、已开票已收款、已开票待收款、在建项目金额。待收款就是还没收到的钱；开票待收属于合同待收的一部分，不重复相加。
- 查看时间与人员范围贯穿工作台、报表、明细钻取。老板及管理员默认公司，主管默认部门和下属，销售默认本人；选主管包含其下属团队。
- 看板显示客户、商机、跟进次数、最近记录和下一步；可直接打开客户及商机跟进。行动计划、关联日程承接推进。
- 业务列表、报表及关联表提供排序依据、正序和倒序；服务端分页先排序权限内全部匹配行。金额列保留正常宽度，手机表格内部横向滚动。
- 渠道作为付款甲方时，实施、开发和外包计业务；软件返佣单列。来源渠道与真实客户分开记录，原报价保留，我方业务金额可另行核实拆分。
- 审批设计、驳回修订、撤回、或签及处理状态留痕；智能体读取使用实时权限，写入行动经预演、人工批准和执行回执。

## 继续使用时的边界

预计收款是可解释规则安排，尚未经历史样本校准，不能视为客户付款承诺。银行、税务及会计接口未开通。外网配置页面和模板已经预留，当前没有真实VPN/HTTPS入口，须配置后再进行外出手机实测。macOS原生多公司安装与单公司Docker流程分别验收；不互相替代。

公开源码与分发包只包含通用代码、虚构数据和公开文档；公司数据库、凭证、备份、上传原件、私有日程和真实客户材料不在分发范围内。
