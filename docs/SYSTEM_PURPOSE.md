# 系统设计目的

伴圆CRM是一套可本地安装的AI操作型客户经营系统。使用人授权AI读取资料，AI整理客户与事项、历史工作和未来计划；系统负责业务关系、权限、状态、审批与可追溯执行。

## 业务标准

方案和PPT支持形成线索；有效报价支持形成商机；多次报价保留版本与内部工作记录；沟通与听记形成有来源的跟进。未签草稿、实际签约、验收、开票与到账分别取证。名称或金额不清楚的保留待核实，不能编造成已发生交易。

每项下一步说明客户事项、负责人、拟定时间、完成依据。计划日期不等于客户承诺；实际完成后再记录反馈。

## 组织与数据

功能权限决定能做什么，数据权限决定能处理哪些记录。老板和管理员查看当前公司，主管查看部门及下属团队，销售查看本人和已授权记录。查询、明细和导出遵守同一范围，客户分配与整体交接保留历史作者。每个公司使用独立MySQL数据库与连接账号。

## 审批与经营

或签保留实际同意人和其他未审核人员状态，会签保留独立决定。AI不能代替实际审批人作决定。合同与开票待收避免重复相加；渠道作为付款甲方的我方业务金额，与终端项目背景、软件返佣分别核对。

## 技术实现与边界

React网页与NestJS服务，MySQL保存业务。网页与智能体适配器共用应用服务。智能体身份来自认证上下文，不接收任意SQL；写入按权限、状态、幂等与版本约束执行并留回执。外部AI和连接工具只有在明确授权后才读取资料，安装本身不取得全部聊天或文件权限。

本地浏览器和手机H5共用数据与权限。钉钉组织、个人日程待办与原生审批分别配置。外出访问通过实际配置的VPN或HTTPS入口；是否可用以连接测试和回执确认。

公开样本全部为天雨虚构内容，真实公司数据与密钥始终保留在部署环境中。
